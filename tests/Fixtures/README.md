# Synthetic media fixture

`media.mkv` is a ten-second 160×120, 25 fps synthetic test pattern with a
440 Hz sine-wave audio track and the two captions in `captions.srt`.
It contains no third-party creative media. It was generated for these tests.

The integration runner uses only the bundled C libraries. Neither generating
this fixture nor installing a command-line FFmpeg tool is required to run it.
